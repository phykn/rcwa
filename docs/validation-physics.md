# Observed numerical validation

Executed 2026-10-10 in the development environment. Results below apply to the described finite examples, not the entire accepted input domain or experimental metrology.

## Reproduce

From the repository root with the pinned development environment:

```sh
PYTHONPATH=backend OPENBLAS_NUM_THREADS=1 .venv/bin/python -m pytest backend/tests/test_physics.py -q
.venv/bin/ruff check backend/rcwa_core backend/tests/test_physics.py
```

Observed: **43 physics tests passed**, about 1.0 s; Ruff passed. An additional S4 reference suite is described in [independent-reference.md](independent-reference.md). It compared all retained order fluxes and total powers in 19 scenarios and 150 polarization/wavelength samples, with maximum absolute difference 2.02×10⁻¹³. Absorbing substrates, high contrast, oblique angles, and multiple propagating orders are included. The report records the exact source revision, basis, and build. Package pins for this run: Python 3.12.14, meent 0.13.2, NumPy 2.5.3, SciPy 1.17.1, Pydantic 2.12.5, pytest 9.0.2. `backend/requirements-lock.txt` records the full application environment.

## Analytic reference checks

The test reference independently implements Fresnel/Airy equations using optical admittances and the public exp(-iωt), n+ik convention. Tests compare **power** R and T; complex amplitude/phase conventions are not validated.

Cases include identity medium, zero-thickness interface, Brewster reflection, total internal reflection, full-width and empty rectangle limits, transparent/absorbing films, and absorbing substrates. Film examples use n=2.1 with k=0,0.2,0.8, thickness 0,137,1500 nm, incidence 0°,31°,67°, and wavelengths 532,632.8,780 nm. Substrate examples are 1.5, 3.5+0.1i, and 0.8+2i. This includes a high-loss substrate but does not claim to be measured silicon data.

A supplementary cross-product measurement of the three angles, four thickness/loss pairs, three substrates, three wavelengths, and two polarizations (216 polarization/wavelength cases) had maximum absolute R/T error **9.99×10⁻¹⁶**. Stored metrics: `docs/validation-physics.json`. The regression tolerance is 2×10⁻¹⁰ absolute plus 2×10⁻¹⁰ relative.

## Patterned physics and numerical behavior

- Lossless grating and passive absorbing grating: period 780 nm, CD 320 nm, height 190 nm, ridge n=2.4 with k=0 or 0.15, angle 12°, wavelengths 450/520/670 nm, ±11 harmonics. Checks include per-order sums, nonzero propagating diffraction, zero ordinary evanescent-port power, and lossless R+T. Passive `A_balance≥0` is checked, but no independent volume absorption integral is claimed.
- Exact vector segment widths and homogeneous topology limits are checked independently of the eigensolver.
- Repeated A→B→A model evaluations and common length/wavelength scaling are checked. Fresh matrices are built for every wavelength; no mutable solver cache is shared.
- Material interpolation, no extrapolation, invalid scope/NaN rejection, exact-cutoff rejection, and insufficient propagating-order basis are tested.
- Centered CD finite differences at 0.2/0.05/0.01 nm steps agree at the declared test tolerance. This is a local sensitivity check, not global identifiability.

### Harmonic refinement example

For the default period 400 nm, CD 180 nm, height 160 nm, n-ridge=2.1, n-background=1, n-substrate=1.5, incidence 15°, both polarizations, and wavelengths 510/650/810 nm, harmonics 3→7→11→15→19 gave consecutive maximum reflectance changes:

- 3→7: 0.00300062190
- 7→11: 0.000333838981
- 11→15: 0.0000714542495
- 15→19: 0.0000258626766

This illustrates improvement for one sample. It is not a universal error bound, and convergence need not be monotonic for other samples. Agreement between engines at the same finite basis alone does not prove a converged physical result.

## Synthetic CD recovery

For the default 21-wavelength grid (450–850 nm, 20 nm step), ±7 harmonics, both polarizations, target CD=207 nm, and bounds 80–300 nm:

- Best fit: 206.9999999999994 nm; equal-weight specular-power RMSE 1.97×10⁻¹⁵
- 48 distinct forward model evaluations; elapsed approximately 1.28 s
- Starts at 124 and 180 nm recovered the target. The 256 nm start stopped near 245.037 nm with RMSE 0.0877, demonstrating a local minimum. The reported best fit was selected by residual, not optimizer success alone.
- Refinement from ±7 to ±11 changed fitted-model specular powers by at most 0.00032077

The target is generated by the identical forward model and basis, so the tiny recovery error is expected and is **not** dimensional measurement accuracy. No noise, model mismatch, uncertainty, or global uniqueness test is claimed.

## Timing and stored example

Default 21-wavelength, both-polarization runs took 0.0270,0.0265,0.0267 s on the available Linux x86-64 development runtime with one OpenBLAS thread, after Python imports. This is a small CPU example, not a service SLA or worst-case limit. Default maximum lossless flux error was 5.44×10⁻¹⁵.

`frontend/public/reference-example.json` contains the exact Project and its genuinely computed forward result. It is a reproducible stored example; it must not be used to imply that edited input was computed. Performance at difficult resonances, the full parameter envelope, or the maximum input budget has not been established.

## Historical single-layer scope and remaining limits

This report records the single-layer validation baseline from 2026-10-10. Multilayer validation had not yet been performed at that point; the subsequent stage is documented in the [current multilayer numerical evidence](validation.md#multilayer-numerical-evidence), including the committed planar and independent S4 comparisons.

Experimental samples, a calibrated material database, an instrument model, roughness, finite targets, conical/2D calculations, a complex amplitude API and measured-data inverse validation remain outside this report. Exact diffraction cutoffs deliberately return a diagnostic. S4 provides independent implementation evidence, but both methods share RCWA assumptions. Strong material contrast/loss, resonances, and near-cutoff cases require their own basis and spectral refinement before interpretation.
